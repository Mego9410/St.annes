# Weekly Newssheets

Place PDF copies of the weekly newsheet here so they can be viewed from the Services & Events page.

**Filename format:** `YYYY-MM-DD.pdf` (e.g. `2026-02-01.pdf` for 1 February 2026).

The list of newssheets shown on the site is in `src/data/newssheets.json`. Add an entry there for each PDF you add:

```json
{ "label": "1 February 2026", "path": "/newssheets/2026-02-01.pdf" }
```
